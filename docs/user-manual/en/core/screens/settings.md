# Settings overview

Settings are grouped by clinic area. On a phone, this page lets you choose a
category. On a desktop, Dentum opens the first category you can access.

1. Select a category such as clinic details, people, clinical settings,
   billing, integrations, or account.
2. Choose a settings page inside that category.
3. Save changes on the page where you made them. Some settings apply
   immediately; pages with a Save button apply changes only after you save.

The categories and pages you can see depend on your role and the installed
modules. If an expected option is missing, ask an administrator to check your
permissions and module availability.
