# Module management

Module management is for administrators. It shows which features are
installed, available, disabled, or waiting for a change.

1. Search by module name or description, or filter the list by status.
2. Open a module to read its description and current health information.
3. Select the change you need, review the confirmation dialog, and confirm
   it. Pending changes are grouped before they are applied.
4. Check the result and resolve any health warning before using the affected
   feature.

Installing, upgrading, or removing a module can change clinic functionality.
Coordinate these changes with your administrator and avoid doing them during
active clinic work.
