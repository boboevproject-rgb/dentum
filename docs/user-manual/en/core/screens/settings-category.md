# Settings category

A category page collects the settings pages for one clinic area. The category
name appears at the top; available pages appear as cards.

1. Use the category navigation to switch to another area.
2. Open a card to edit a specific setting. The card description explains what
   it controls.
3. Use the back link on a narrow screen to return to the category list.

Some pages are provided by optional modules. A category can be visible while
one or more module pages are unavailable because the module is not installed
or your role does not have access.
