# Administración de módulos

La administración de módulos está destinada a personas administradoras.
Muestra qué funciones están instaladas, disponibles, desactivadas o pendientes
de un cambio.

1. Busca por nombre o descripción, o filtra la lista por estado.
2. Abre un módulo para consultar su descripción e información de estado.
3. Selecciona el cambio que necesitas, revisa el diálogo de confirmación y
   confírmalo. Los cambios pendientes se agrupan antes de aplicarse.
4. Comprueba el resultado y resuelve cualquier aviso antes de usar la función
   afectada.

Instalar, actualizar o quitar un módulo puede cambiar las funciones de la
clínica. Coordina estos cambios con la persona administradora y evita hacerlos
durante la atención de pacientes.
