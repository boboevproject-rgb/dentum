# Resumen de configuración

La configuración se organiza por áreas de la clínica. En un teléfono, esta
pantalla permite elegir una categoría. En un ordenador, Dentum abre la primera
categoría disponible para tu cuenta.

1. Elige una categoría, como datos de la clínica, personas, ajustes clínicos,
   facturación, integraciones o cuenta.
2. Selecciona una página dentro de esa categoría.
3. Guarda los cambios en la página donde los hiciste. Algunos ajustes se
   aplican de inmediato; las páginas con un botón Guardar aplican los cambios
   solo después de guardarlos.

Las categorías y páginas visibles dependen de tu rol y de los módulos
instalados. Si falta una opción, pide a una persona administradora que revise
tus permisos y la disponibilidad del módulo.
