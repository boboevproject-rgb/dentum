# Categoría de configuración

La página de una categoría reúne los ajustes de un área de la clínica. El
nombre de la categoría aparece arriba y las páginas disponibles se muestran
como tarjetas.

1. Usa la navegación de categorías para cambiar a otra área.
2. Abre una tarjeta para modificar un ajuste. Su descripción explica qué
   controla.
3. En una pantalla estrecha, usa el enlace de volver para regresar a la lista
   de categorías.

Algunas páginas las proporcionan módulos opcionales. Puede que una categoría
esté visible aunque no puedas abrir alguna página porque el módulo no está
instalado o tu rol no tiene acceso.
